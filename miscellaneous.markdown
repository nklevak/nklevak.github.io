### Grad school resources

<a href="https://psychology.stanford.edu/diversity/paths-phd" target="_blank" rel="noopener noreferrer">Paths to PhD</a> — Workshop and 1:1 mentorship for developing a Psychology PhD application. There are a lot of programs like this held by different Psychology programs!

<a href="https://womenincocosci.com/index.html" target="_blank" rel="noopener noreferrer">Women in CoCoSci</a> — Has really useful information about computational cognitive science with a list of labs + application resources.
